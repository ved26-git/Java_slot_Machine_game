A simple console-based Slot Machine game built with Java.
This project is designed to practice Java fundamentals such as loops, arrays, methods, user input, random number generation, conditional statements, and switch expressions.

Features:

Starts with a balance of $100
Generates 3 random slot symbols

🍕 🍔 🥪 🍩 🍪 Multiple symbols

Allows the player to place bets

Prevents bets greater than the current balance

Prevents zero or negative bets

Different payout multipliers for different symbols

Allows the player to continue playing

Displays the final balance when the game ends


How the Game Works:

The player starts with a balance of $100.

The player enters the amount they want to bet.

The game randomly generates 3 symbols.

If two or three symbols match, the player receives a payout.

The payout depends on the matching symbol.

The player can choose to play another round or exit.

The game ends when the player runs out of money or chooses N.
